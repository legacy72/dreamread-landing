# DreamRead Landing - Agent Guide

## Product Positioning - Read First

**DreamRead = auto-pause for audiobooks when the listener falls asleep.**

This landing page is for a sleep-focused audiobook auto-pause app, not a generic audiobook player, reader, book catalog, meditation app, or sleep tracker.

Main scenario:

1. The user listens to an audiobook before bed.
2. The user falls asleep.
3. DreamRead detects the sleep transition through Apple Watch / pulse signals.
4. DreamRead pauses playback so the user does not lose their place.

All copy, SEO metadata, ad landing variants, screenshots, pricing language, and CTA framing should preserve that promise.

## Copy Rules

- Lead with `fall asleep listening -> auto-pause -> keep your place`.
- Mention honestly that Apple Watch is required for automatic sleep detection.
- Treat library/import/catalog/player controls as supporting mechanics, not the main differentiated value.
- Do not reposition DreamRead as a generic `audiobook player`, `reader`, `free books app`, or `catalog`.
- If a keyword or section uses generic audiobook language, tie it back to bedtime auto-pause.

## Preferred Phrases

- `Auto-pause audiobooks when you fall asleep`
- `Fall asleep to audiobooks without losing your place`
- `Apple Watch-powered audiobook auto-pause`
- `Audiobooks that pause when you do`
- `Засыпайте под аудиокниги - DreamRead поставит на паузу, когда вы уснёте`
